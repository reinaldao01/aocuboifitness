# AOCUBO FITNESS — importação no Bolt

Este pacote contém o site completo, incluindo layout, animações, responsividade e todas as imagens usadas no projeto.

## Caminho recomendado

1. Extraia o ZIP no computador.
2. Envie a pasta para um repositório novo no GitHub.
3. No Bolt, escolha **Import from GitHub** e selecione o repositório.
4. Aguarde a instalação das dependências.
5. Se o Bolt pedir um comando, use `npm run dev`.
6. Confira o número e a mensagem do WhatsApp em `app/page.tsx`, na constante `WHATSAPP`.
7. Publique pelo botão **Publish** do Bolt.

## Prompt para enviar ao Bolt depois da importação

> Analise este projeto Next.js existente e preserve integralmente seu design, textos, imagens, animações, responsividade e interações. Não reconstrua a página, não substitua fotos e não altere a identidade visual. Apenas corrija eventuais incompatibilidades necessárias para executar e publicar no Bolt. Mantenha a página em português do Brasil, todos os links internos, o menu móvel, o carrossel da hero, os efeitos de entrada, os cards de produtos, os links do WhatsApp e o comportamento responsivo. Antes de finalizar, execute o build e corrija qualquer erro sem modificar o visual.

## Observação

Não use apenas um prompt para recriar o site. A importação deste código é o que preserva a versão atual com fidelidade.
